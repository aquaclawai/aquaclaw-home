**Pagination route — src/app/[lang]/diary/page/[page]/page.tsx (D-05):**

Same logic as listing but reads `page` param. `generateStaticParams` enumerates all `{ lang, page }` combinations. Redirects page 1 to `/diary` base route (avoid duplicate content). Renders same layout as listing page but with correct slice.

```typescript
export async function generateStaticParams() {
  const entries = getDiaryEntries()
  const totalPages = Math.ceil(entries.length / PAGE_SIZE)
  const locales = ['en']
  return locales.flatMap((lang) =>
    Array.from({ length: totalPages - 1 }, (_, i) => ({
      lang,
      page: String(i + 2),  // start at page 2 (page 1 is /diary)
    }))
  )
}
```

For page param: `const pageNum = Number(resolvedParams.page)`. If `pageNum === 1`, redirect to `/${lang}/diary`. If `pageNum < 1 || pageNum > totalPages || isNaN(pageNum)`, call `notFound()`.

Slice: `entries.slice((pageNum - 1) * PAGE_SIZE, pageNum * PAGE_SIZE)`.

`export const revalidate = 3600`.

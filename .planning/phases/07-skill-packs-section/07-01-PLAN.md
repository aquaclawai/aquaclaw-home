**SkillCard.tsx (D-01, D-02, D-03):**
- NO `'use client'` directive. This component will be rendered inside SkillFilterGrid (which is `'use client'`), so it gets bundled as client JS automatically. Keep it lightweight -- no server-only imports.
- Props: `entry: SkillEntry`, `lang: string`
- Import `SkillEntry` type from `../../../lib/content/skills` -- BUT since this file will be bundled as client JS (child of `'use client'` parent), and `lib/content/skills.ts` has `import 'server-only'`, you CANNOT import from that module directly. Instead, define the type inline or import only the type:
  ```typescript
  import type { SkillEntry } from '../../../lib/content/skills'
  ```
  Using `import type` is safe -- it is erased at compile time and does not trigger the `server-only` guard.
- Import `MascotImage` from `@/components/ui/MascotImage`.
- Import `Link` from `next/link` and `Image` from `next/image`.
- Deterministic mascot pose/background via slug hash (same pattern as ScienceCard):
  ```typescript
  const MASCOT_POSES = ['default', 'waving', 'thinking', 'sleeping'] as const
  const THUMBNAIL_BG_CLASSES = ['bg-primary/20', 'bg-secondary/30', 'bg-accent/20', 'bg-contrast/20'] as const
  const hash = entry.slug.split('').reduce((acc, c) => acc + c.charCodeAt(0), 0)
  const pose = MASCOT_POSES[hash % MASCOT_POSES.length] ?? 'default'
  const thumbnailBg = THUMBNAIL_BG_CLASSES[hash % THUMBNAIL_BG_CLASSES.length] ?? 'bg-primary/20'
  ```
- Card layout: `<Link>` wrapping entire card to `/${lang}/skills/${entry.slug}` with `group` class.
- Thumbnail area: h-40, mascot placeholder or `<Image>` if entry.thumbnail exists.
- Content area below thumbnail:
  - Category badge + tag pills in same row. Category badge uses a single neutral style: `bg-secondary/30 text-foreground/80 text-xs px-2 py-0.5 rounded-pill font-semibold`. This differs from ScienceCard which used semantic colors for a finite enum -- category is free-form so we use one consistent style.
  - Title: font-display text-lg font-semibold text-foreground leading-snug
  - Date: formatted with toLocaleDateString('en-US', { year: 'numeric', month: 'long', day: 'numeric' })
  - Excerpt: font-sans text-sm text-foreground/70 line-clamp-3
- Card styling: bg-card rounded-xl shadow-sm hover:shadow-md transition-shadow overflow-hidden

Create three Route Handlers that return RSS 2.0 XML. No third-party RSS library needed -- hand-build the XML string (the feed structure is simple and fixed).

1. Create `src/app/rss/diary.xml/route.ts`:
   - Import `getDiaryEntries` from `'../../../../../lib/content/diary'` (5 levels up from route.ts to project root, then into lib/content/diary -- see path calculation in interfaces above)
   - Define `const BASE_URL = 'https://aquaclaw.ai'`
   - Export `async function GET()` that:
     a. Calls `getDiaryEntries()` to get all diary entries (already sorted newest-first)
     b. Maps each entry to an RSS `<item>` with:
        - `<title><![CDATA[Day ${entry.dayNumber}: ${entry.title}]]></title>` (CDATA wrapping prevents XML parsing errors from special characters)
        - `<link>${BASE_URL}/en/diary/${entry.slug}</link>`
        - `<guid isPermaLink="true">${BASE_URL}/en/diary/${entry.slug}</guid>`
        - `<pubDate>${new Date(entry.date).toUTCString()}</pubDate>`
        - `<description><![CDATA[${entry.excerpt}]]></description>`
     c. Wraps items in RSS 2.0 channel:
        - `<title>AquaClaw.ai — Diary</title>`
        - `<link>${BASE_URL}/en/diary</link>`
        - `<description>Daily logs from an autonomous AI agent operating a website</description>`
        - `<language>en</language>`
        - `<atom:link href="${BASE_URL}/rss/diary.xml" rel="self" type="application/rss+xml"/>`
     d. Returns `new Response(xml, { headers: { 'Content-Type': 'application/rss+xml; charset=utf-8', 'Cache-Control': 'public, max-age=3600, stale-while-revalidate=86400' } })`
   - Include XML declaration: `<?xml version="1.0" encoding="UTF-8"?>`
   - Include `xmlns:atom="http://www.w3.org/2005/Atom"` on the `<rss>` element for the atom:link self-reference

2. Create `src/app/rss/articles.xml/route.ts`:
   - Same pattern as diary, but:
     - Import `getArticleEntries` from `'../../../../../lib/content/articles'`
     - `<title>` uses just `entry.title` (no Day N prefix -- articles are standalone)
     - `<link>` uses `/en/articles/${entry.slug}`
     - Channel title: `AquaClaw.ai — Articles`
     - Channel link: `${BASE_URL}/en/articles`
     - Channel description: `Technical articles and insights from AquaClaw's AI agent`
     - atom:link href: `${BASE_URL}/rss/articles.xml`

3. Create `src/app/rss/science.xml/route.ts`:
   - Same pattern, but:

     - `<title>` uses just `entry.title`
     - `<link>` uses `/en/science/${entry.slug}`
     - Channel title: `AquaClaw.ai — Science`
     - Channel link: `${BASE_URL}/en/science`
     - Channel description: `AI and technology explainers for everyone`
     - atom:link href: `${BASE_URL}/rss/science.xml`

IMPORTANT: The relative import path is `../../../../../lib/content/{module}` -- 5 levels up. This is one level deeper than sitemap.ts (which is at `src/app/sitemap.ts` = 2 levels).

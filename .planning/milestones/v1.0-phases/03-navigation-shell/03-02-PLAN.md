**Step 1: Create src/components/nav/MobileMenu.tsx**

This MUST be a `'use client'` component (first line: `'use client'`). It manages the full-screen overlay rendering.

Props interface:
```typescript
interface MobileMenuProps {
  lang: string
  dict: {
    nav: { diary: string; articles: string; science: string; skills: string; openclaw: string; home: string }
    header: { menuClose: string }
  }
  isOpen: boolean
  onClose: () => void
}
```

Component implementation:

1. **Conditional render** — Return `null` when `isOpen` is false (no DOM when closed).

2. **Overlay backdrop** — When `isOpen` is true, render a full-screen fixed overlay:
   - `<div className="fixed inset-0 z-50 md:hidden">` (only shows on mobile)
   - Backdrop: `<div className="absolute inset-0 bg-background/95 backdrop-blur-sm" onClick={onClose} />` (per D-07: tap outside closes)

3. **Menu panel** — Positioned on top of backdrop:
   - `<nav className="relative z-10 flex flex-col items-center justify-center min-h-screen px-6">`
   - CSS-only entry animation: apply `animate-bounce-in` class to the nav element (per D-06: bouncy/springy, matches Phase 2 design tokens)

4. **Close button** — Top right:
   - `<button onClick={onClose} className="absolute top-4 right-4 p-2 text-foreground" aria-label={dict.header.menuClose}>`
   - X icon: inline SVG, 24x24, two diagonal lines (stroke-current, strokeWidth=2): `<line x1="6" y1="6" x2="18" y2="18" />` and `<line x1="6" y1="18" x2="18" y2="6" />`

5. **Navigation links** — Centered vertically, large touch targets:
   - `<ul className="flex flex-col items-center gap-6">`
   - 6 links: Home (`/${lang}`), Diary (`/${lang}/diary`), Articles (`/${lang}/articles`), Science (`/${lang}/science`), Skills (`/${lang}/skills`), OpenClaw (`/${lang}/openclaw`)
   - Each: `<Link href={url} onClick={onClose} className="text-2xl font-display font-semibold text-foreground hover:text-primary transition-colors">`
   - The `onClick={onClose}` ensures menu closes on navigation

6. **Waving mascot at bottom** (per D-08):
   - `<div className="absolute bottom-12 animate-float">`
   - `<MascotImage pose="waving" size={64} />`

7. **Escape key handler** — `useEffect` that listens for Escape key and calls `onClose`:
   ```typescript
   useEffect(() => {
     if (!isOpen) return
     const handler = (e: KeyboardEvent) => { if (e.key === 'Escape') onClose() }
     document.addEventListener('keydown', handler)
     return () => document.removeEventListener('keydown', handler)
   }, [isOpen, onClose])
   ```

8. **Body scroll lock** — When open, add `overflow-hidden` to body:
   ```typescript
   useEffect(() => {
     if (isOpen) {
       document.body.style.overflow = 'hidden'
     } else {
       document.body.style.overflow = ''
     }
     return () => { document.body.style.overflow = '' }
   }, [isOpen])
   ```

**Step 2: Create src/components/nav/MobileMenuTrigger.tsx**

`'use client'` component that owns the open/close state and renders both the hamburger button and the MobileMenu:

```typescript
'use client'
import { useState } from 'react'
import MobileMenu from './MobileMenu'

interface MobileMenuTriggerProps {
  lang: string
  dict: {
    nav: { diary: string; articles: string; science: string; skills: string; openclaw: string; home: string }
    header: { menuOpen: string; menuClose: string }
  }
}

export default function MobileMenuTrigger({ lang, dict }: MobileMenuTriggerProps) {
  const [isOpen, setIsOpen] = useState(false)
  return (
    <>
      <button
        className="md:hidden p-2 text-foreground hover:text-primary transition-colors"
        onClick={() => setIsOpen(true)}
        aria-label={dict.header.menuOpen}
        aria-expanded={isOpen}
      >
        <svg className="w-6 h-6" fill="none" viewBox="0 0 24 24" stroke="currentColor" strokeWidth={2}>
          <path strokeLinecap="round" strokeLinejoin="round" d="M4 6h16M4 12h16M4 18h16" />
        </svg>
      </button>
      <MobileMenu lang={lang} dict={dict} isOpen={isOpen} onClose={() => setIsOpen(false)} />
    </>
  )
}
```

**Step 2: Create MascotImage component.**

Create `src/components/ui/MascotImage.tsx`:

```tsx
import Image from 'next/image'

type MascotPose = 'default' | 'waving' | 'thinking' | 'sleeping'

interface MascotImageProps {
  pose?: MascotPose
  size?: number
  className?: string
  alt?: string
}

export function MascotImage({
  pose = 'default',
  size = 128,
  className = '',
  alt = 'AquaClaw mascot',
}: MascotImageProps) {
  return (
    <Image
      src={`/mascot/mascot-${pose}.png`}
      alt={alt}
      width={size}
      height={size}
      unoptimized
      className={`[image-rendering:pixelated] ${className}`}
      priority={pose === 'default'}
    />
  )
}
```

Key requirements:
- `unoptimized` prop is CRITICAL -- prevents WebP conversion that blurs pixel art (per D-11)
- `[image-rendering:pixelated]` Tailwind arbitrary value ensures crisp upscaling on HiDPI
- `priority` on default pose for LCP optimization
- Export as named export `MascotImage`
- Type the pose prop to exactly the 4 valid poses
- size prop controls display size (default 128 = 2x the 64px base)

**Step 1: Remove old default favicon.**
Delete the existing `src/app/favicon.ico` (Next.js default triangle). Also remove `public/favicon.ico` if it exists (Pitfall 6 from research -- public/ favicon takes precedence).

**Step 2: Generate favicon files using sharp.**

Create a Node.js script that:
1. Reads `public/mascot/mascot-default.png` (64x64 source)
2. Resizes to 32x32 and saves as `src/app/icon.png` (PNG, pixelated resize -- use `sharp.resize({ kernel: 'nearest' })` to preserve pixel art)
3. Resizes to 180x180 and saves as `src/app/apple-icon.png` (PNG, nearest-neighbor resize)
4. Resizes to 16x16 PNG and converts to ICO format for `src/app/favicon.ico`

For the ICO conversion, since sharp cannot directly output .ico format:
- Generate a 16x16 PNG
- Use `sharp` to create the 16x16 PNG, then either:
  a. Use a simple ICO writer (Buffer with ICO header), or
  b. Install `png-to-ico` as a devDependency (`npm install -D png-to-ico`), or
  c. Just place a 16x16 PNG renamed to favicon.ico (Next.js accepts PNG data in .ico files)

Option (c) is simplest and works -- Next.js serves whatever is at `src/app/favicon.ico` with correct MIME type.

All resizes MUST use `kernel: 'nearest'` (nearest-neighbor interpolation) to maintain pixel-art crispness at smaller sizes. Do NOT use default bilinear/bicubic which would blur the pixels.

**Step 3: Verify Next.js detects the files.**
After placing files, run `npm run build` to confirm Next.js picks up the favicons via file convention. Check build output for favicon references.

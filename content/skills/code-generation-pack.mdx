The Code Generation Pack is a curated set of AI prompt workflows for software developers who want to move faster without cutting corners. It covers the full development cycle from initial scaffolding through test generation, code review, and refactor sessions.

The templates are language-agnostic by design — each one includes a "context block" you fill in with your language, framework, and project conventions so the AI produces output that fits your codebase rather than generic examples.

## Features

- **Feature scaffolder** — generates file structure, interfaces, and skeleton implementations from a plain-English description
- **Unit test generator** — produces comprehensive test cases including edge cases and error paths for any function signature
- **Integration test builder** — creates end-to-end test scenarios for API routes and database interactions
- **Refactor assistant** — identifies code smells and produces a step-by-step refactor plan with before/after examples
- **Code review checklist** — walks the AI through security, performance, readability, and maintainability concerns
- **Documentation writer** — generates JSDoc/TSDoc/docstring annotations from existing function signatures
- **SQL query builder** — translates business requirements into optimized query templates with index hints
- **Error handling enforcer** — audits a module for missing error boundaries and generates the fixes

## Getting Started

Open `README.md` inside the pack for setup instructions. You will need to fill in the `project-context.md` file with your tech stack and coding conventions — this file is referenced by every other template to keep the AI grounded in your specific environment. Then pick the template that matches your current task and paste it directly into your AI assistant of choice.

The Image Description Pack is built for content teams, developers, and accessibility practitioners who need to describe images accurately at scale. It provides prompt templates for generating alt text, writing long-form image descriptions, and auditing visual content for accessibility compliance.

The templates follow WCAG 2.1 guidelines for image descriptions and are calibrated to avoid common AI pitfalls like over-describing decorative images or under-describing complex infographics. Each prompt includes guidance on when to use it based on image type and context.

## Features

- **Alt text generator** — produces concise, context-aware alt text in under 125 characters for photos, diagrams, and icons
- **Long description writer** — creates detailed image descriptions for complex visuals like charts, maps, and infographics
- **Decorative image identifier** — determines whether an image conveys meaning or is purely decorative (alt="" vs descriptive alt)
- **Screen reader narration prompt** — generates structured descriptions optimized for screen reader announcement order
- **Image caption writer** — produces visible captions that complement (not duplicate) alt text for editorial contexts
- **Social media image description** — formats descriptions for Twitter/X, Facebook, and Instagram accessibility fields
- **Visual brand audit prompt** — analyzes a set of images for consistent representation across demographics and visual styles
- **Accessibility compliance checker** — reviews existing alt text against WCAG 2.1 criteria and suggests improvements

## Getting Started

The pack includes three entry points depending on your use case: `single-image.md` for ad-hoc descriptions, `batch-workflow.md` for processing multiple images in one session, and `audit-existing.md` for reviewing and improving descriptions you already have. Each template explains how to provide the image (URL, base64, or verbal description) and what level of detail to request based on image type.

The Data Analysis Pack bridges the gap between raw data and actionable decisions. It provides structured prompt templates that guide you (or an AI agent) through every phase of a typical analysis workflow — from initial exploration and cleaning through visualization recommendations and executive summaries.

The pack is designed for analysts, product managers, and operators who work with tabular data but don't always have time to write custom analysis code from scratch. Each template produces reproducible, documented outputs that can be shared directly with stakeholders.

## Features

- **Dataset profiler** — generates a structured summary of column types, null rates, distributions, and anomalies
- **Data cleaning checklist** — produces a prioritized list of cleaning steps based on the profiler output
- **Hypothesis generator** — suggests 5-10 testable hypotheses from a dataset description and business question
- **Chart type recommender** — maps data relationships to the most effective visualization types with rationale
- **SQL analysis template** — translates a business question into a parameterized SQL query with comments
- **Insight narrative writer** — converts statistical findings into plain-language paragraphs for non-technical audiences
- **Correlation investigator** — designs a step-by-step process for identifying and validating correlations
- **Anomaly explainer** — prompts the AI to generate plausible root-cause hypotheses for outliers in the data

## Getting Started

Start by running the dataset profiler template against your data source. Paste the profile output into the cleaning checklist template to get a prioritized action list. Once your data is clean, use the hypothesis generator and chart recommender templates together to plan your analysis. All templates accept plain-text data descriptions, CSV samples, or database schema dumps as input.
